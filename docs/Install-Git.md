# Installing Git

## What is Git?

Imagine you're writing an important document and you want to save a copy every time you make a big change — so you can always go back if something goes wrong. **Git** does exactly that, but for software code.

---

## Step-by-Step Installation

### Windows

1. Open your web browser and go to **[git-scm.com](https://git-scm.com)**
2. The website will automatically detect you're on Windows and show a **Download** button — click it
3. A file called something like `Git-2.x.x-64-bit.exe` will download
4. Open it from your Downloads folder by double-clicking it
5. A setup wizard will appear. The default options are fine — just keep clicking **Next** until you reach **Install**
6. Click **Install**, wait for it to finish, then click **Finish**

That's it! Git is now installed.

### Mac

Git often comes pre-installed on Macs. Let's check first:

1. Press `Cmd + Space`, type `Terminal`, and open it
2. Type the following and press Enter:
   ```
   git --version
   ```
3. **If you see a version number** (like `git version 2.39.x`) — Git is already installed, you're done!
4. **If a dialog box pops up** asking you to install developer tools — click **Install** and follow the prompts. This will install Git automatically.
5. **If nothing happens or you get an error** — go to **[git-scm.com](https://git-scm.com)**, download the Mac installer, and run it.

---

## How to Check It Worked

1. Open **Command Prompt** (Windows) or **Terminal** (Mac)
2. Type the following and press Enter:
   ```
   git --version
   ```
3. You should see something like `git version 2.45.0` — any version number means it's working

If you see a version number, you're all set!
