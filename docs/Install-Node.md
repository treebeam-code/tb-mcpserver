# Installing Node.js

## What is Node.js?

Think of Node.js as the **engine** that powers the TreeBeam MCP server. Just like a car needs an engine to run, the MCP server needs Node.js installed on your computer to work. You don't need to write any code — you just need it installed and running in the background.

---

## Step-by-Step Installation

### Windows

1. Open your web browser and go to **[nodejs.org](https://nodejs.org)**
2. You'll see two big green buttons. Click the one labeled **"LTS"** (this stands for "Long Term Support" — it's the stable, recommended version)
3. A file called something like `node-v22.x.x-x64.msi` will download to your Downloads folder
4. Open that downloaded file by double-clicking it
5. A setup wizard will appear — just click **Next** through all the steps and then **Install**
6. When it finishes, click **Finish**

That's it! Node.js is now installed.

### Mac

1. Open your web browser and go to **[nodejs.org](https://nodejs.org)**
2. Click the **"LTS"** button to download
3. A file called something like `node-v22.x.x.pkg` will download
4. Open it from your Downloads folder
5. Follow the on-screen prompts — click **Continue**, **Continue**, **Install**
6. You may be asked for your Mac password — this is normal, enter it and click **Install Software**

That's it! Node.js is now installed.

---

## How to Check It Worked

After installing, you can confirm Node.js is ready:

1. **Windows:** Press the Windows key, type `cmd`, and open **Command Prompt**
   **Mac:** Press `Cmd + Space`, type `Terminal`, and open it
2. Type the following and press Enter:
   ```
   node --version
   ```
3. You should see something like `v22.0.0` — any number starting with 22 or higher is perfect

If you see a version number, you're all set!
